# Handoff - January 23, 2026

## Session Summary
Added a changelog notification system with version tracking and "never show again" option.

## What Was Implemented

### 1. Changelog Notification Component
**File:** `archive/src/components/ChangelogNotification.astro`

- Fixed position bottom-left popup
- Shows: version badge, title, bullet list of changes
- Two dismiss options:
  - "X" button → dismisses for current version only
  - "Don't show again" → permanent opt-out
- Appears 2.5s after page load
- Links to `/about#changelog` for full history

**localStorage keys:**
- `changelog-last-seen` - stores last dismissed version (e.g., "1.1.0")
- `changelog-never-show` - stores "true" if user opted out permanently

### 2. Changelog Data File
**File:** `archive/src/data/changelog.json`

### 3. About Page - Version History Section

### 4. BaseLayout Integration
**File:** `archive/src/layouts/BaseLayout.astro`

## How to Add Future Updates

1. Edit `archive/src/data/changelog.json`
2. Update `currentVersion` to new version
3. Add new entry to beginning of `entries` array:
   ```json
   {
     "version": "1.2.0",
     "date": "2026-XX-XX",
     "title": "Brief Title",
     "changes": ["Change 1", "Change 2"]
   }
   ```
4. Commit and push - notification will auto-show for users
