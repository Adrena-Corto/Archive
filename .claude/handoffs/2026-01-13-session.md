# Session Handoff - 2026-01-13

## Accomplished

### 1. Fixed Timeline Not Loading on First Visit
- **Issue**: PixiJS timeline canvas wasn't rendering on initial page load
- **Root cause**: Race condition where `initTimeline()` ran before CSS layout completed, resulting in `clientWidth`/`clientHeight` being 0
- **Fix**: Added dimension check with `requestAnimationFrame` retry loop in [Timeline.astro:181-186](archive/src/components/timeline/Timeline.astro#L181-L186)
- **Also**: Changed initialization marker from immediate `'true'` to `'pending'` during init, then `'true'` after successful completion

### 2. Made Timeline Category Filters More Subtle
- **Before**: Larger pill buttons with borders, full words, prominent styling
- **After**: Minimal text-only buttons, 8px font, no borders, 50% opacity container that reveals on hover
- **Files**: [Timeline.astro:62-69](archive/src/components/timeline/Timeline.astro#L62-L69) (HTML) and [Timeline.astro:415-424](archive/src/components/timeline/Timeline.astro#L415-L424) (styles)

### 3. Fixed Articles Page Tag Filter Scrolling
- **Issue**: Tag filter buttons couldn't be scrolled horizontally when they overflow
- **Fix**: Moved `overflow-x-auto` to the buttons container with `min-w-0` to allow shrinking
- **Also**: Removed "Topic" prefix label, simplified count display
- **File**: [index.astro:112-145](archive/src/pages/library/articles/index.astro#L112-L145)
- **User addition**: Added wheel-to-scroll handler for horizontal scrolling with mouse wheel

## Key Decisions

1. **requestAnimationFrame retry for canvas dimensions**: Chose this over `setTimeout` because rAF aligns with browser paint cycles, making it more reliable for catching when layout is complete

2. **Text-only filter buttons**: Removed borders and backgrounds to make filters less visually dominant while keeping them functional and accessible via hover state

3. **Removed "Topic" label from articles filter**: The filter context is clear from the page heading and button labels; the label added visual noise without value
