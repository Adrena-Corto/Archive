## Key Decisions

### featuredItems Must Match Article Content
- Only add items to `featuredItems` if they actually appear in the article body via `collection-embed`
- This prevents showing misleading item previews for articles that don't actually feature those items

### Reused Timeline Popup Pattern
- Used same `.visible` class approach as Timeline component
- Global CSS in `global.css` handles opacity/visibility transitions
- Avoids CSS specificity issues with Tailwind utilities vs ID selectors

### Inline Script with define:vars
- Used `is:inline` directive to ensure script runs after DOM is ready
- `define:vars` passes server-side data (items JSON, base URL) to client script
- Plain JavaScript (not TypeScript) for inline scripts
