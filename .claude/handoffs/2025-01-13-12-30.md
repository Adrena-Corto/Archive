## Key Decisions

- **Used CSS classes instead of Astro component**: Markdown articles can't import Astro components directly. CSS pattern in `<style is:global>` works with raw HTML in markdown.
- **Avoided @apply for grid utilities**: Tailwind's `grid-cols-2` caused circular dependency error. Used plain CSS `display: grid; grid-template-columns: repeat(2, minmax(0, 1fr));` instead.
- **Dual image layout as default**: Most collection items benefit from showing two views (obverse/reverse for coins, dorsal/base for scarabs).
