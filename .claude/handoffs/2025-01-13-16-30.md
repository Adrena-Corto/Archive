## Key Decisions

1. **50px clustering threshold** - Items within 50 pixels cluster into thumbnail grids
2. **80px label collision threshold** - Separate from thumbnail clustering, handles cases where thumbnails are separate but labels would overlap
3. **Grid-based cluster layout** - Max 2 columns, items shrink based on count: `Math.max(24, 48 / Math.sqrt(count))`
4. **Bottom-aligned clusters** - Cluster grid bottom aligns with single thumbnail bottom (not centered)
5. **Popup over navigation** - Items open in modal to keep user on timeline page
6. **3-line labels** - Changed from 2-line to allow more text, reducing truncation
7. **Immediate diamond hiding** - Old cluster diamonds hidden immediately (not animated out) to prevent flickering
