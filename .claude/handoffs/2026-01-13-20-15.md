## Key Decisions

- **Film strip vs grid carousel**: User preferred a continuous "pellicule" effect over a single-image carousel. Images are duplicated for seamless loop, 25s animation duration.

- **Timeline orientation**: Changed from vertical to horizontal to match the actual Timeline page. Positioned higher (`top-8`) to be visible above the text overlay.

- **Animation triggers**: All animations start on hover (mouseenter) and pause on mouseleave. This keeps the page calm when not interacting.

- **Spacing reduced**: Changed section padding from `py-20 md:py-28` to `py-12 md:py-16` to be consistent with other homepage sections.

- **Accessibility**: Added `prefers-reduced-motion` media query to disable animations for users who prefer reduced motion.
