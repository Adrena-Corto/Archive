## Key Decisions

### Service Worker over Cloudflare Proxy
User chose service worker because:
- No infrastructure changes needed
- Works on any host
- More control over caching logic
- Trade-off: Requires cache version management on deploys

### Cache Strategies
- **Cache-first for hashed assets**: Astro bundles include content hash in filename, safe to cache forever
- **Network-first for HTML**: Ensures users get fresh content, with offline fallback
- **No precaching**: Avoided to keep initial SW install fast; assets cached on-demand

### Silent Registration
Used `.catch(() => {})` because:
- SW registration can fail in private browsing modes
- Failure is non-critical (site still works without it)
- Avoids console errors that might confuse users/developers
