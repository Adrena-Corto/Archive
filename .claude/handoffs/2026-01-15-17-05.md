## Key Decisions

- **Switched from `define:vars` to `set:html`**: Astro's `define:vars` wasn't properly serializing the `baseUrl` variable in the inline script. Using `set:html` with template literal interpolation (`${JSON.stringify(baseUrl)}`) ensures the value is correctly embedded.

- **URL normalization with regex**: Used `.replace(/\/+/g, '/')` pattern to handle cases where `baseUrl` is `/` and path starts with `/`, preventing double slashes that get interpreted as protocol-relative URLs.

- **Kept `/item/` singular route**: The existing route is at `src/pages/item/[id].astro`. Rather than create a new `/items/` route for backwards compatibility, fixed all references to use the correct singular form.
