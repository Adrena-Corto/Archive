## Key Decisions

1. **Used `serve` instead of `astro preview`** - Astro's preview mode was injecting dev toolbar elements that interfered with selectors. Using `npx serve dist` serves the actual static build cleanly.

2. **URL-based filter testing** - Tests verify URL params are set correctly rather than checking DOM visibility changes. This is simpler and catches the core functionality (state persistence) without fighting Alpine.js timing.

3. **Separate chromium/mobile projects** - Tests run on both Desktop Chrome and iPhone 14 viewport to catch responsive issues.

4. **Screenshot threshold of 0.2 with 100px max diff** - Allows minor anti-aliasing differences while catching real visual regressions.
