## Key Decisions

### Animation Strategy
Chose layered elements with `opacity`/`transform` over CSS `will-change` because:
- More reliable compositor promotion
- Works consistently across browsers
- No risk of excessive layer creation

### Matrix Effect Optimization
Chose `requestIdleCallback` over `IntersectionObserver` because:
- Matrix canvas is always visible (fixed position background)
- Idle callback better suited for "nice to have" visual effects
- 2-second timeout ensures effect eventually starts

### Particle Count Reduction
200/100 (desktop/mobile) chosen because:
- Original 300 was excessive for subtle background effect
- Mobile reduction more aggressive due to thermal/battery constraints
- Still provides good visual density at reduced cost

### CSS Inlining
Set to `'auto'` rather than `'always'` because:
- Lets Astro decide based on file size
- Avoids bloating HTML for larger stylesheets
- Best balance of initial load vs caching
