## Key Decisions

1. **ThumbHash over BlurHash**: ThumbHash produces smaller hashes (28 bytes) with better color accuracy
2. **Canvas-based placeholders**: Allows dynamic decoding without extra network requests
3. **Priority threshold of 6**: Covers typical 3x2 above-the-fold grid on desktop
4. **Prebuild automation**: Ensures manifest is always current without manual steps
5. **fetchpriority="high"**: Modern browser hint for prioritizing above-the-fold images
6. **Separate badges container**: Fixes z-order issues where badges were hidden behind thumbnails
